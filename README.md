# Album Photo (TD 3 Laravel)

Gestionnaire d'albums photo sur le thème de l'espace. Binôme : Gabin et Lenny.

## Installation après un clone

1. `composer install`
2. Copier `.env.example` en `.env`
3. `php artisan key:generate`
4. Importer `database/album_photo.sql` dans MySQL
5. `php artisan serve`
